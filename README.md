项目描述：本项目根据整理、存储、检索和协作编辑图片的需求，提供用户注册登录、空间（个人/团队）与配额管理、图片多方式上传与存储、分类标签检索、按主色搜索、管理员审核、空间数据分析，以及基于 WebSocket 的多人在线协同编辑和外接ai搜索和扩图等功能。
技术描述：
独立完成 MySQL 数据库表设计与 ER 图（用户、空间、空间成员、图片等核心表）；
基于 Spring Boot 搭建服务，搭配 MyBatis-Plus 简化数据库操作，搭建 Controller / Service / Manager / Mapper 分层结构，开发用户、空间、图片等三十多个业务接口；
空间建立三级角色权限，通过 Sa-Token 重写权限接口、注解鉴权，将权限校验从业务代码中解耦；
图片上传支持本地、腾讯云 COS、外部链接三种方式，采用模板方法模式统一上传与校验流程；
基于 WebSocket + Disruptor 独立实现多人在线协同编辑机制，解决编辑互斥、实时广播等问题；
封装ai扩图、ai图像搜索等第三方 API，增加图库功能；
使用 Vue 3+Ant Design Vue 完成全部前端页面，包括用户端（搜索/详情/上传/空间）与管理端（用户 / 图片 / 空间 / 成员管理），完成可复用组件（图片列表、上传、裁剪、扩图、批量编辑）；
